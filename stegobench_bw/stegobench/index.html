Method

From a secret to a ranked leaderboard in five steps

  1. 1

    Choose cover and secret

    Pick one image or a whole folder. Type a message or choose a file, then set a passphrase.

  2. 2

    Protect the payload

    The secret is encrypted with AES-256-GCM, wrapped with a length and checksum, and given Reed-Solomon error correction.

  3. 3

    Hide it

    Each selected method embeds the bits: LSB variants, DCT, spread spectrum, DWT or content-adaptive S-UNIWARD.

  4. 4

    Attack and extract

    The stego image is attacked, then the message is read back with the same key and compared with the original.

  5. 5

    Score and rank

    Robustness, invisibility, detectability and capacity combine into a ranking you can reweight for your goal.

Attacks

What happens inside one attack test

For every method and every attack, StegoBench repeats the same six steps and records how much of the message survived.

  1. 1

    Take the stego image

    The image that already holds the hidden bits, as lossless PNG or saved as JPEG at quality 90.

  2. 2

    Apply the attack

    For example a real browser JPEG re-encode at quality 75, a 50% resize, Gaussian noise or a 3-pixel shift.

  3. 3

    Extract with the same key

    The method reads the bits back from the attacked image and never sees the original cover.

  4. 4

    Correct errors

    Reed-Solomon decoding repairs flipped bytes when error correction is on, equally for every method.

  5. 5

    Compare with the original

    Recovery is chance adjusted: a 50% bit match counts as 0%, a perfect match as 100%.

  6. 6

    Add to the scores

    All attacks average into the robustness score and fill one cell of the attack heat map.
